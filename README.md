A responsive Myntra-inspired e-commerce website developed using HTML, CSS, and JavaScript. This project recreates the look and feel of an online fashion shopping platform with a focus on frontend design, user interaction, and responsive layouts.

🚀 Features
🏠 Home page with fashion-focused sections
👕 Product listings and product cards
🔍 Search functionality
🛒 Shopping bag/cart interface
❤️ Wishlist interface
📱 Responsive design for different screen sizes
🎨 Modern and user-friendly UI
⚡ JavaScript-based interactive elements
🧭 Navigation between different sections/pages
🛠️ Technologies Used
HTML5 – Structure and content
CSS3 – Styling, layouts, animations, and responsiveness
JavaScript – Interactivity and dynamic functionality

💻 How to Run
Clone or download this repository.
Open the project folder.
Open MyntraClone.html in a web browser.
Explore the website and its interactive features.

No backend server or database setup is required for the frontend version of this project.
